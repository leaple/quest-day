# QUEST DAY 캐릭터 일러스트

이 폴더에는 1.3 캐릭터 12종의 PNG를 업로드할 수 있습니다.

각 파일명은 다음과 같이 고정합니다.

- sprout.png
- paper_messenger.png
- dawn_runner.png
- sunset_scribe.png
- forest.png
- clockkeeper.png
- star_scribe.png
- ninja.png
- mage.png
- knight.png
- dream_whale.png
- time_guardian.png

앱의 `upgrade-1.3.js`는 `./art/{id}.png` 경로를 자동으로 불러옵니다.
이미지가 없는 경우에는 동일한 캐릭터의 인라인 SVG 그림으로 대체합니다.

사용자 퀘스트, 레벨, 골드 등은 별개로 기기 로컬 저장소에 유지됩니다.

# QUEST DAY 캐릭터 진화 일러스트 · v33

12종 공식 캐릭터 × 진화 3단계 = **총 36개** 독립 SVG 그림.

## 파일 규칙
`art/evolution/{character_id}-stage{1|2|3}.svg`

캐릭터 ID:
- sprout · 새싹 모험가
- paper_messenger · 종이비행기 메신저
- dawn_runner · 새벽 러너
- sunset_scribe · 저녁 기록가
- forest · 숲의 연금술사
- clockkeeper · 시계탑 관리자
- star_scribe · 별조각 서기
- ninja · 그림자 러너
- mage · 별빛 마법사
- knight · 달빛 기사
- dream_whale · 꿈고래 소환사
- time_guardian · 시간의 수호자

각 SVG에는 기존 게임 내 원본 캐릭터 PNG를 내장해 외부 파일 로드 오류를 줄였으며, 단계에 따라 오라/마법 문양/동작 궤적/광원 파티클을 추가합니다. 이는 **독립적인 단계별 합성 일러스트**이며 의상과 인물 자체를 완전히 다시 그린 신규 PNG와는 다릅니다.

**1단계:** 캐릭터 전체 실루엣과 여백에 집중; 기본 배경광.
**2단계:** 캐릭터 고유 능력별 에너지 원, 정령/상징 효과, 광원과 추가 장식.
**3단계:** 더 큰 광륜과 다중 에너지 궤적, 강한 블룸, 마법 입자 및 문양.

단계 변경은 기존 `upgrade-1.3.js`의 `evolutionStage(character)`를 사용하며 `characters-1.3.json`의 해금 조건은 변경하지 않습니다. 홈·성장·도감에 같은 그림을 렌더링합니다. 서버 저장/퀘스트/XP/구매/캐릭터 보유 상태에는 영향을 주지 않습니다.

파일이 존재하지 않는 경우에는 기존 `art/{id}.png`를 사용하고, 이미지 로드에 실패한 경우에는 앱의 기본 SVG 그림을 사용합니다.

기존 1.2 전용 우주 개척자(astronaut)는 12종 캐릭터 카탈로그와 별개의 호환용 외형이며 진화 규칙이 없으므로 본 36종에는 포함하지 않습니다.

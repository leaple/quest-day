# QUEST DAY 1.8 — 안정화 및 친구 계정 보호

기존 퀘스트·골드·캐릭터·친구 기록은 유지됩니다. 새로운 SQL은 **필요하지 않습니다**.

## 업데이트 내용

- **채팅 안정화:** 실시간 수신·동기화 시 채팅 입력창을 유지해 아이폰 키보드와 작성 중인 글의 손실을 줄입니다. 오래된 메시지 조회 결과가 최신 결과를 덮어쓰지 않도록 순서를 확인합니다.
- **아이폰 사용성:** 채팅 영역의 터치 스크롤, 키보드 입력 크기, 버튼 크기를 개선합니다.
- **알림:** 친구 탭의 새 소식 배지, 앱 내부 알림 접근성 개선. 응원은 '모두 읽음'을 직접 누르기 전까지 읽지 않은 상태로 유지합니다. **앱 종료 후 푸시 알림은 아직 지원하지 않습니다.**
- **계정 보호(선택):** 익명 친구 계정을 이메일로 인증한 뒤 비밀번호를 설정합니다. 이미 보호한 친구 계정이라면 다른 기기에서 이메일과 비밀번호로 로그인할 수 있습니다.
- **원격 XP 보호:** 다른 기기에서 기존 친구 계정으로 로그인하면 서버 XP를 덮어쓰지 않도록 자동 성과 업로드를 일시 정지합니다. 사용자 확인 후 다시 시작할 수 있습니다.

## 계정 보호 사용 전 Supabase 설정

Supabase Dashboard → **Authentication → Sign In / Providers**에서 Email 제공자를 사용하도록 설정하고, **Authentication → Settings**의 **Allow manual linking**을 활성화해야 할 수 있습니다. 메뉴 위치는 버전별로 달라질 수 있습니다.

Supabase의 [Anonymous Sign-Ins 문서](https://supabase.com/docs/guides/auth/auth-anonymous)에 따라 익명 사용자가 이메일을 연결할 때 `auth.updateUser({email})`을 사용하고, 인증을 마친 다음 `auth.updateUser({password})`로 비밀번호를 설정합니다.

기본 Supabase 이메일 발송에는 빈도 제한이 있으며, 실제 서비스에서는 인증 이메일 발송 설정(커스텀 SMTP 등)을 별도로 검토해야 합니다.

## 아이폰에서 보호하기

1. QUEST DAY 최신 버전을 열고 **설정 → 친구 계정 보호**로 이동합니다.
2. **현재 친구 계정을 이메일로 보호하기**를 펼칩니다.
3. 본인이 관리하는 이메일로 인증 요청을 보내고 받은 메일의 안내에 따라 인증합니다. 6자리 코드가 제공된 경우 앱의 코드 입력란으로 인증할 수도 있습니다.
4. **인증 상태 다시 확인**으로 확인한 뒤 비밀번호(12자 이상)를 설정합니다.
5. 다른 기기에서도 실시간 친구 기능을 켠 후 **설정 → 다른 기기에서 기존 친구 계정으로 로그인하기**를 이용할 수 있습니다.

**참고:** 이 기능은 친구·채팅 계정의 로그인 복구를 위한 것입니다. 게임의 퀘스트·골드·캐릭터 데이터는 여전히 원래 기기의 로컬 저장소에 있습니다. 기기를 바꾸기 전 **설정 → 데이터 백업**으로 JSON을 따로 저장하고 새 기기에서 복원해야 합니다.

## 복구 시 원격 XP 안전장치

기존 친구 계정으로 다른 기기에서 로그인하면 서버 측 레벨·XP를 자동으로 새 기기의 값으로 덮어쓰지 않도록 **성장 기록 동기화가 일시 중지**됩니다. 원래 기기의 로컬 데이터 백업을 확인한 후 **이 기기의 성장 기록으로 동기화 재개** 버튼을 눌러야 합니다. 주의: 재개 후에는 새 기기 값이 서버 표시 값을 변경할 수 있습니다.

## 개인정보와 보안

- 이메일 및 비밀번호는 Supabase Auth와 직접 주고받습니다. QUEST DAY의 친구 프로필, 채팅 메시지, 로컬 퀘스트 저장 데이터에는 이메일·비밀번호를 추가하지 않습니다.
- 비밀번호 자체를 GitHub에 입력하거나 친구에게 공유하지 마세요. 다른 서비스에서 쓰는 비밀번호 재사용도 피하세요.
- 계정 보호 기능은 **선택 사항**입니다. 지금처럼 익명 로그인만 사용하면 앱 데이터를 지우거나 기기를 옮겼을 때 원래 익명 친구 계정을 복구할 수 없습니다.
- 이 기능은 비밀번호 분실 후 이메일 재설정을 구현한 것은 아닙니다. 비밀번호 분실 시 Supabase 인증 정책에 따른 복구 절차를 별도로 준비해야 합니다.
- 앱 설치나 브라우저 데이터 초기화는 기존 로컬 데이터가 손실될 수 있으므로 충분히 백업하기 전에는 하지 마세요.
- 기존 채팅의 신고·차단 기능은 유지됩니다.

## 테스트 체크리스트

1. 친구 탭에서 채팅을 입력하는 도중 다른 친구가 메시지를 보냈을 때 키보드가 닫히거나 문구가 사라지지 않는지 확인합니다.
2. 친구 응원 알림 수신 후 친구 탭 배지가 표시되고, 알림의 **모두 읽음**을 누르면 사라지는지 확인합니다.
3. 설정의 **친구 계정 보호**가 나타나는지 확인합니다.
4. 이메일 연결을 선택했다면 확인 메일을 받고 인증·비밀번호 설정을 완료합니다.
5. 다른 기기의 로그인 기능을 사용했다면 XP 업로드 일시 중지가 표시되는지 확인하고, 게임 데이터 백업을 먼저 복원합니다.
